# ClipForge AI - Android V1

ClipForge AI is an AI-powered video clipping app designed to turn long videos into short, engaging clips.

## V1 Goals

- Select videos from phone storage
- Preview videos
- Trim videos
- Automatically cut videos into short clips
- Save exported clips to phone
- Simple and mobile-friendly interface

## Core Features

1. Video Import
2. Video Preview
3. Manual Trim
4. Auto Clip Cutting
5. Clip Export
6. Save to Gallery

Android
